# 📁 Arquivo Confidencial: Entregas

Bem-vindos à base de dados central da Agência. É aqui que os códigos das **Fichas Secretas** de todas as equipes ficarão armazenados após a aprovação das missões.

### ⚠️ Regras de Operação nesta pasta:

1. **O seu diretório:** No Fork de vocês, criem uma única pasta aqui dentro. O nome da pasta deve seguir estritamente o padrão `equipe-X` (substitua o X pelo número da sua equipe. Exemplo: `equipe-1`).
2. **Isolamento de Dados:** Todos os arquivos do seu projeto (`index.html`, arquivos de perfil, `.css`, imagens e o relatório `ENTREGA.md`) devem ser colocados **exclusivamente** dentro da pasta da sua equipe.
3. **Restrição Máxima:** É expressamente **proibido** alterar, excluir ou mover qualquer outro arquivo ou pasta do repositório inteiro, incluindo este próprio `README.md`. A sua equipe só tem permissão para atuar *dentro* da pasta `equipe-X` que vocês irão criar. A Varredura Final anulará a missão se detectar alterações fora da sua pasta no Pull Request.

### 🗺️ Estrutura Esperada
Quando vocês enviarem o Pull Request do Fork para cá, a organização da entrega deverá estar exatamente assim:

```text
entregas/
├── README.md           ← Você está aqui. Não altere este arquivo!
├── equipe-X/           ← Diretório da sua equipe (criado no Fork)
│   ├── index.html
│   ├── ENTREGA.md
│   ├── style.css       (ou os seus vários arquivos .css numa pasta)
│   ├── membro-a.html
│   └── membro-b.html
```
